## Looking for mods?

This website explains how to *create* content for TrackDayR. If you are looking for mods that are ready to
download and play, the community gathers them on [tdrmods.com](https://tdrmods.com), where you can find bikes,
tracks and rider gear.

The easiest way to install them is the [Mod Manager](/modding/mod-manager/), a desktop app that browses that same
catalog and puts every file in the right place for you.

:::caution[We are not affiliated with tdrmods.com]
tdrmods.com is an independent website run by the community. It is not owned, managed or endorsed by TrackDayR, and
we have no control over the files hosted there. We link it because our players find it useful, but anything you
download from it is at your own risk, and any request for support about that content should go to its authors.
