The TrackDayR Mod Manager is a free desktop app that browses the [tdrmods.com](https://tdrmods.com) catalog and installs
any mod for you, with no manual downloading, unzipping or folder hunting.

It is made by the MadCow team for the TrackDayR community.

## Features

- Browse the full catalog of bikes, tracks and rider gear, with thumbnails and descriptions
- One-click install: the app downloads, unpacks and places every file in the right directory
- Automatic detection of your game folder through the TrackDayR mod path system
- A "Your Mods" tab to review what you have installed and remove it
- Automatic updates of the app itself
- Available in English, French and Italian
- Optional anonymous usage analytics

## Requirements

The app runs on Windows. There is nothing to install and no Python installation is required.

Tested with TrackDayR version 1.0.124.206.

## How to install a mod

1. Download the app and run it
2. On the first launch Windows may show a security warning: click `More info` then `Run anyway`
3. Open the **Mods Catalog**, pick the content you want and click **Add to library**
4. Start TrackDayR: the mods are ready to use
